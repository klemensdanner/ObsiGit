We can use bold or italic text, we can also use underline text. And then there is also small text and big text. We can also use deleted text or strike-through for not correct anymore text. Note that most of these elements are not used anymore, because they are not semantic. Or they have been given a semantic meaning after the fact. There are only some possibilities for styling text, because, you know, there is css and HTML should in general not be used for styling. We also have a quote element, which is used for short inline quotes. For longer quotes we can use the blockquote element.

For long quotes, use the blockquote element. This is a blockquote. It can contain multiple paragraphs and citations.

Showing Code

And, then of course, important for us, we have the code element:
#include <stdio.h>
int main() {
printf("Hello, World!");
return 0;
}
 You can see that we can't use all characters and need to format the code. code is used for inline code snippets, for larger code blocks we can use the pre element: 
         
            #include <stdio.h> 
            int main() {
                printf("Hello, World!");
                return 0;
            }
